# ADR-0009: Target scope pinned to M0 (phases 0-5)

| | |
|---|---|
| **Status** | Superseded by ADR-0015 |
| **Date** | 2026-07-19 |
| **Type** | Scope |

## Context

The original plan had 14 phases (M0-M5). The user wanted a committed, finishable target.

## Decision

The committed target was M0, the end of Phase 5: quant exact-match >= 90%, 100% typed refusal on unanswerable questions, zero look-ahead, every number cited. Phases 6-9 were optional polish; 10-13 shelved.

## Consequences

Replaced by the learning-focused roadmap in ADR-0015.
