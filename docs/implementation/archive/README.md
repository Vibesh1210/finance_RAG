# Archive — the original design and plan (v0.3, 2026-07-10)

Kept unchanged (apart from a one-line "archived" banner at the top), for two reasons:

1. **The code cites them.** Comments like "design §6.1" or "execution plan Phase 3" refer
   to `design_us.md` and `execution_plan_us.md` in this folder.
2. **They hold the original intent** for anything not yet built (see
   `../future_scope.md`), plus the pinned decisions U1–U13 (execution plan, Part 0.2) and
   the risk/pivot table (Part III).

They are **not** a description of the current system — several parts were built
differently or cut. For what is actually built, read `docs/production/` (its HLD §8 lists
every difference). For what gets built next, read `../roadmap.md`.
